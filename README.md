## このリポジトリについて

サイト本体（React / Vite）と、サイトを運用する管理画面（問い合わせ・予約・口コミ・SNS・アクセス解析・SEO / AIO の計測など）が入っています。Vercel で動いています。

```
npm install
npm run dev      # 手元で動かす
npm run build    # 本番と同じ手順で作る
```
